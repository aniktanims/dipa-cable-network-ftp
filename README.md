# DHAKA FLIX Movie Fetcher

Desktop app for browsing and downloading movies and series from the DHAKA FLIX servers (172.16.50.x).

- Every section (English, Hindi, South Indian, Animation, TV series, Korean, Anime, ...) with year / A–Z shelves
- Opens on the newest year and remembers where you left off
- Instant filter, plus search across all sections (press Enter)
- TMDB ratings, plots and trailers; Download, Copy link, Play in VLC
- My List for saving titles

## Run

| How | Command |
| --- | --- |
| Desktop app (dev) | `run-dev.bat` or `npm run dev` |
| In the browser | `start.bat` or `npm start`, then open http://localhost:8000 |
| Build the Windows app | `build.bat` → `dist/MovieFetcher-Portable.exe` and `dist/win-unpacked/` |

Needs access to the DHAKA FLIX network.
